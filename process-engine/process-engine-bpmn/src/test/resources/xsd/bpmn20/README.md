# BPMN 2.0 XML schema

`BPMN20.xsd`, `Semantic.xsd`, `BPMNDI.xsd`, `DC.xsd` and `DI.xsd` are the unchanged schema files of OMG BPMN 2.0
(document formal/2011-01-03), from `https://www.omg.org/spec/BPMN/20100501/`. They are test resources only: the
PRE-034 tests validate exported documents against them without network access. They are not shipped in any artifact.
